# CLIPJOY BACKEND
The robust backend engine powering Clipjoy, a full-stack video streaming and community platform built using Node.js, Express, and MongoDB.

## FEATURES
- User Authentication & Authorization (JWT)
- Video Upload & Management (Cloudinary)
- User Profiles & Social Interactions (Follow, Like, Comment)
- Video Streaming & Playback
- RESTful API Endpoints for Seamless Frontend Integration
- Secure Password Hashing (bcrypt)

## TECH STACK
- Node.js & Express.js
- MongoDB & Mongoose
- Cloudinary (Media Storage)
- JSON Web Tokens (JWT) & bcrypt
